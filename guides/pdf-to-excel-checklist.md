# Convert PDF to Excel free: a workbook checklist

A useful spreadsheet needs complete rows, correctly placed values, and clear column meanings. When you convert PDF to Excel online, use this checklist before conversion and when reviewing the workbook.

## 1. Check the source

Open every page you plan to use. Look for missing edges, faint text, rotated pages, and tables that continue onto the next page. Keep a copy of the original document beside the exported workbook.

Try selecting a word in the PDF. Selectable text suggests a text layer is present; an image-only page needs text recognition. A document can contain both kinds of page, so check more than the first page.

## 2. Decide what each row represents

Choose one unit for a row, such as an order, an invoice item, or a bank transaction. Keep document titles, repeated column headers, subtotals, and notes separate from those records.

If a table crosses a page boundary, check the last row of one page against the first row of the next. A repeated heading should not become another record, and a wrapped description should not become a second item.

## 3. Review the workbook

| Check | What to compare with the PDF |
| --- | --- |
| Row count | Each source record appears once. |
| Column alignment | Descriptions, quantities, and amounts stay in their intended columns. |
| Identifiers | Leading zeros and full reference numbers are preserved. |
| Dates | Day and month follow the source convention. |
| Amounts | Decimal separators, negative signs, and currencies remain clear. |
| Totals | Comparable amounts reconcile after allowing for stated tax, fees, and discounts. |

Leave unclear values for review rather than filling them from context. When making a correction, record the original value and the source page so someone else can check it.
